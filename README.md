# -ACE-Dynamic-Web-Portal-
A Online Book Reading Dynamic Web Portal For College Students
This web Portal is still a Prototype 

**Features of the web Portal**
1. Login System
2. session check

 **Session Check** this helps the user to automatically logout from the web portel after 10 sec of inactivity.
 User will return to the login page which protects the privacy.
